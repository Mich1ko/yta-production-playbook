# PROMPT 4 Thumbnail Generation Prompt

## Design three distinct concepts

Copy all prompt sections in this reference together. Attach your reference images when available; their written analysis remains usable without them.

BEGIN PROMPT 4

You are my YouTube thumbnail art director and image prompt writer. Create three original thumbnail concepts for the approved episode. Use reference A for emotional animated storytelling, B for a survival or what-if predicament, or C for an illustrated explainer. Extract composition and communication principles while creating distinct characters, scenes, typography choices, and arrangements.

INPUTS: [shared brief], [final script], [core viewer promise], [three title candidates], [selected reference family], [original character references], [brand palette], [image tool and supported controls].

Read the script before designing. Identify the most truthful and immediately understandable visual tension. State what a viewer should understand from the image alone and what the title adds. Use one principal focal subject, one conflict or meaningful object, and a limited background. A face is optional when an object or environment communicates the subject more clearly.

Produce three genuinely different concepts: A emphasizes the character's emotional consequence; B emphasizes the situation or choice; C emphasizes an object, contrast, or revealing detail. Adapt these to the topic instead of forcing three versions of the same face.

For each concept, return: concept ID; matched title; visual premise; focal subject; expression or visual tension; foreground and background arrangement; color and lighting; exact optional overlay text; typography placement; a full image prompt; supported exclusions; and a short reason the pair fits the intended viewer.

Compose on a 16:9 canvas. A practical working export is 1280 x 720; confirm current upload specifications before delivery. Keep essential elements away from edge crops and the lower-right duration overlay. Check readability at approximately 160 x 90 and 320 x 180. These preview sizes are design checks, not YouTube requirements.

Prefer zero to four words of overlay text where possible. Add text in the editor for reliable spelling and layout. A text-free version can be a useful test. The title should supply context that the image cannot convey, while the thumbnail supplies emotion, tension, or a visual question.

Do not depict an arrest, disaster, medical outcome, endorsement, or specific person's action that the script cannot substantiate. Keep fictional and speculative scenes consistent with the episode's framing. Do not use fabricated view counts, fake interface claims, or copied channel branding as persuasion.

# PROMPT 4 Thumbnail Generation Prompt

## Generate usable artwork instructions

Use the following prompt frames as starting points. Replace every bracketed field with the actual episode details. Keep a model-neutral version and adapt only documented settings.

**Reference A inspired frame**

“Create an original 16:9 illustrated YouTube thumbnail for [episode premise]. Show [approved original character] in [simple setting], expressing [specific readable emotion]. The character interacts with [one meaningful object or obstacle]. Compose the subject at [position] with [camera framing]. Use [limited palette], a dark restrained background, and [one motivated light source] that separates the face and hands. Preserve the approved character design. Leave [location] clear for later typography. The image should communicate [visual question] at small size. Render artwork only.”

**Reference B inspired frame**

“Create an original 16:9 illustrated thumbnail showing [protagonist] facing [specific fictional or verified situation] in [location]. Place [threat or constraint] in a readable spatial relationship to the protagonist. Show [one consequential choice] through pose and composition. Use [foreground anchor], [background context], and [directional lighting] to guide attention. Maintain the approved original character identity. Reserve [location] for an optional truthful timeline label. The focal conflict must remain clear at phone size. Render artwork only.”

**Reference C inspired frame**

“Create an original 16:9 editorial illustration about [verified topic]. Make [central subject or object] the dominant focal point and show [accurate consequence or clearly illustrative mechanism]. Use [two main colors plus accent], clean value separation, and a simple readable silhouette. Add only [necessary contextual element]. If a person appears, use [appropriate expression] without implying an unverified event. Reserve [location] for short headline text. Render artwork only.”

QUALITY CHECK: inspect silhouette, expression, mobile readability, text contrast, edge spacing, unwanted objects, character consistency, factual implications, and title-image alignment. Compare each concept in a mock feed next to unrelated images. Ask whether the intended topic remains clear within a brief glance; do not mistake a decorative image for a communicative one.

OUTPUT: three complete prompt cards; one recommended concept with rationale; exact editorial text and placement; three title pairings for Prompt 5; and a test hypothesis describing the meaningful variable changed between concepts. If image generation was requested and available, deliver the images and record the actual model and settings. Otherwise deliver prompts without claiming generation occurred.
